## Adding more

- **iPhone photos:** GitHub doesn't show HEIC. Export as JPG (or set Camera → Formats → Most Compatible).
- **Size:** browser upload takes files up to 25 MB. 720p is plenty for videos; keep photos under ~1–2 MB.
- **Videos that play right in the page:** edit a `.md` file on github.com and drag the video into the text box — GitHub uploads it (~10 MB on a free account) and inserts a player.
